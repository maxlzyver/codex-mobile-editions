V1.3.1 · 插件一键安装

- 新增 Windows 双击 Install-Plugin.cmd 安装插件，支持把软件文件夹拖到安装工具上。
- macOS 双击 Install-Plugin.command 默认进入一键安装。
- 自动查找完整软件目录和 Codex，复用软件自带 Node.js 并完成本地插件注册，无需安装 npm、输入命令或手工添加插件市场。
- 一键安装不模拟鼠标键盘、不切换或操作 Codex 窗口，不打开浏览器、登录窗口或启动助手后台。安装时不必提前打开 Codex，但必须已安装 Codex；首次连接手机前需要电脑端已登录。
- 优先沿用已有工作目录，首次使用且没有配置时准备 Documents/Codex-Mobile-Workspace。多个候选安装不会被随意选择，错误时给出修正说明。
- 保留手动安装入口，以及 1.3.0 的蓝白界面、原图标、当前页批准设备、手机权限和更新功能。

本次只更新插件与安装工具；Windows 11、Windows 10 和 macOS 软件仍使用 1.3.0，不需要重新下载或重新配对。

使用教学

1. 先安装 Codex，并完整解压与你系统相符的 Editions 1.3.0 软件包。安装插件时无需提前打开 Codex。
2. 下载 codex-mobile-plugin-1.3.1.zip，完整解压，将插件文件夹放到软件文件夹旁边。
3. Windows 双击插件目录中的 Install-Plugin.cmd；macOS 双击 Install-Plugin.command。终端显示进度，工具不控制其他窗口。Windows 也可以把完整软件文件夹拖到 Install-Plugin.cmd 上明确指定。
4. 完成后自行打开 Codex，在“插件 → Codex 移动助手”中点“打开插件”。Codex 已运行时关闭再启用本插件，必要时自行重开 Codex；工具不会强制重启。
5. 确认电脑端 Codex 已登录，在插件中生成二维码，手机扫码后直接在当前页面批准连接。

已有 1.3.0 插件可在插件更新页检查并更新到 1.3.1；运行版本需在宿主重新加载后生效。安装位置和故障处理见 V1.3.1-PLUGIN-INSTALL.md。
