# 安装 V1.0.1 重制版并保留本机数据

本次只修正整轮折叠：过程说明、命令执行、文件修改和工具记录收进同一个区域，最终答复单独显示。原 V1.0.1 功能全部保留。

下载：[V1.0.1 重制版完整安装包](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.0.1-rebuild.1)。请选择与现有安装相同的系统专用版，不要使用 GitHub 自动生成的 Source code ZIP。

## 为什么需要手动换装

按本次重制要求，程序版本仍为 **1.0.1**。现有更新器仅接受更高版本，已安装旧 V1.0.1 时，“检查更新”仍会显示最新。GitHub 锁定了原发布包，新包使用发布标签 `v1.0.1-rebuild.1`，没有更改原发布的文件。

若当前为 **V1.0.0 专用版**，可直接在电脑端“设置 → 更新与关于 → 检查更新”安装仓库提供的重制版。

## 已安装旧 V1.0.1：覆盖程序文件

1. 等待助手中的任务结束，然后退出移动助手。Windows 从托盘退出；macOS 运行原目录中的 `Stop.command`。无需退出其他应用。
2. 备份现有助手文件夹，包括隐藏的 `.runtime`。它包含本机配置、配对、手机权限和项目入口，不要删除。
3. 将新的完整 ZIP 解压到一个临时目录，把包内程序文件**合并到原安装目录**，遇到同名程序文件选择覆盖。保留原目录里的 `.runtime`、个人文件和项目目录，不要先删除原安装目录。
4. 从原安装目录启动助手，刷新手机网页。展开“思考与过程”应能同时看到过程说明与执行记录，收起后仅保留一行总入口。

### Windows 10 / Windows 11

在资源管理器打开解压后的 `codex-mobile-windows10` 或 `codex-mobile-windows11` 文件夹，将其中内容复制到原助手文件夹，选择“替换目标中的文件”。这是合并文件内容，不是删除原文件夹再放入新文件夹。

### macOS

Finder 的“替换文件夹”可能移除原文件夹内容，请使用文件合并。可在终端运行以下命令，将两个示例路径替换为自己的实际路径；目标必须是原助手的程序根目录，而非它的上级目录：

```sh
ditto "/完整路径/新解压的/codex-mobile-macos" "/完整路径/原来的/codex-mobile-macos"
```

此命令合并文件并保留新包里没有的 `.runtime` 和个人文件。随后从原目录运行 `Start.command`。

配对配置仍保存在原安装目录。重启后的互联网临时地址可能变化，若旧手机入口不可用，请在电脑重新打开连接入口。不要清空浏览器 Cookie 或运行数据来完成此次换装。

如果换装后无法启动，先退出助手，再使用第 2 步备份恢复原程序目录。不会通过本说明自动操作正在运行的任务。
