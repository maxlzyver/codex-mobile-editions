- Windows 11 和 Windows 10 版各执行 246 项 Node 测试：245 通过，1 项按环境跳过；macOS 版在 Windows 上执行 245 项：243 通过，2 项按环境跳过。macOS 的原生启动与升级另在 Apple 芯片和 Intel runner 上验证。

## 实际 Codex 宿主

验收环境：Windows 11，Codex `26.1007.9446.0`，隔离插件 `codex-mobile@codex-mobile-local`，共享测试软件后台。未向真实聊天发送测试消息，未重启整个 Codex，未修改其他插件。

已验证插件详情的“打开插件”直接打开内嵌页面，不新建聊天；六栏目可用，二维码实际渲染。详情原生设置与内嵌手机权限均执行关闭→开启→关闭，真实后台权限文件同步；重复启动复用同一后台进程。

实际验收发现并修复两项宿主兼容问题：MCP 命令必须使用宿主允许的可执行文件名，且由插件核对实际运行组件；Windows 的插件进程必须离开可替换缓存目录，才能在运行期间刷新缓存。旧进程保留已加载页面，避免更新后读取已移动路径失败。

最终修正版从发布 ZIP 安装到本机 Codex，之后用户接手手动验收并于 2026-10-15 授权上传发布。用户未提供逐项验收记录，因此不把这次发布授权写成所有项目均已通过。

按用户要求停止追加测试，最终一轮 [CI](https://github.com/maxlzyver/codex-mobile-editions/actions/runs/38657534545) 已取消。真实 Codex 宿主内“插件自动下载升级→重新加载新版”以及一键更新的完整流程未完成代理验收；此前已通过的更新器与浏览器模拟测试不能替代该项。未验证 macOS Codex 桌面插件界面。
