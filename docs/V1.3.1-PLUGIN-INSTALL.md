# V1.3.1 软件包内插件安装教学

软件与插件均为 **1.3.1**。完整软件 ZIP 已内置插件，下载一个软件包即可。

## 下载与准备

1. 从 [1.3.1 完整软件发布页](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.3.1-rebuild.1) 下载与你系统相符的 ZIP：Windows 11、Windows 10 或 macOS。
2. 完整解压到当前用户可写的目录，保留所有子文件夹；不要在压缩包内直接运行。GitHub 自动生成的 Source code 不含运行组件，不能代替软件包。
3. 电脑已经安装 Codex。**安装插件时不必提前打开 Codex，也不用先启动移动助手软件。** 实际连接手机前，电脑端 Codex 需要已经登录。

## 一键安装

- Windows：进入解压后的软件文件夹，双击根目录 **`Install-Plugin.cmd`**，它与 `Codex-Mobile.exe` 在同一层。
- macOS：双击软件文件夹根目录 **`Install-Plugin.command`**，它与 `Start.command` 在同一层。首次打开未签名脚本可按系统提示通过 Finder 右键“打开”。

工具直接绑定所在软件目录，使用包内插件和 Node.js 注册到 Codex，不需要单独下载插件、安装 npm、输入命令或手工添加插件市场。不要把安装工具单独移出软件文件夹；以后也应保留这份完整软件目录，插件运行时仍需要它。

安装不会模拟鼠标键盘、切换或控制 Codex 窗口、弹出浏览器或账号登录、启动助手后台、强制重启 Codex。用户双击打开的终端显示进度，结束后退出，不需要按键确认。

已有项目配置优先沿用；首次没有配置时建立 `Documents/Codex-Mobile-Workspace`。插件数据默认保存在 Windows `%LOCALAPPDATA%\CodexMobile\plugin` 或 macOS `~/Library/Application Support/CodexMobile/plugin`；已有自定义绑定时沿用原数据目录。结果写入该目录的 `install-result.txt`。

## 打开插件并连接手机

1. 安装完成后自行打开 Codex，进入“插件 → Codex 移动助手”，点击“打开插件”。它直接显示手机连接管理页面。
2. Codex 原本已打开时，可关闭再启用本插件；若还没出现，再自行重开 Codex。工具不会替你关闭聊天或重启程序。
3. 电脑端 Codex 已登录后，生成局域网或互联网二维码；手机扫码后，在当前插件页面的待批准卡片中点“批准连接”。
4. 插件的设置入口可以直接调整手机权限；页面保留手机连接、设备、手机权限、使用说明、更新、关于。也可在对话中说“打开移动助手管理面板”。
5. “更新”里分别设置软件和插件的检查更新、一键更新、自动更新。自动更新默认关闭；显示“待 Codex 重新加载”时，需由宿主重新加载后才使用新版本。

详细功能见 [V1.3 插件使用教学](V1.3.0-PLUGIN-GUIDE.md)。独立软件仍可通过 Windows `Codex-Mobile.exe` 或 macOS `Start.command` 使用，网页界面保留。

## 旧版在线升级与故障处理

从旧版在线升级到 1.3.1 并重启助手后，软件会自动在根目录生成 **`Install-Plugin.cmd`**（Windows）或 **`Install-Plugin.command`**（macOS），与完整 ZIP 的入口一致。`tools/` 中也保留相同安装入口。此前已经升级到 1.3.1 而根目录缺失的安装，可以直接运行 `tools/` 中的入口，或将该 CMD / command 文件复制到软件根目录；相同版本不会重复安装更新。已有插件无需重复安装，仍可在插件中更新。

- 安装入口或运行组件缺失：重新完整解压对应软件 ZIP；不要下载 Source code，也不要只复制 CMD 文件。
- 提示找不到 Codex：先安装兼容的 Codex 再重试。工具不会自动下载安装另一份 Codex。
- 窗口很快关闭：查看软件目录 `.runtime/plugin-install-result.txt` 和插件数据目录 `install-result.txt` 中的结果。
- 插件缓存被占用：自行关闭插件后重试；必要时自行退出再打开 Codex。安装工具不会强行结束进程。
- 需要自定义路径：独立插件包继续保留原手动安装接口，见仓库 `plugins/codex-mobile/README.md`。
