# V1.3.1 插件一键安装教学

V1.3.1 更新插件和安装工具，独立软件继续使用 V1.3.0。无需重新配对或重新下载已有的软件。

## 准备

1. 电脑已安装 Codex。**安装插件时不必提前打开 Codex**；实际使用手机连接时，电脑端需已登录 Codex。
2. 已完整解压 [V1.3.0 软件包](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.3.0)，文件夹内应有 `edition.json`、`server.mjs` 与 `runtime`。GitHub 自动生成的 Source code ZIP 没有运行组件，不能代替软件包。
3. 下载并完整解压 [V1.3.1 插件包](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.3.1)，把 `codex-mobile-plugin` 文件夹放在完整软件文件夹旁边，例如同一“下载”目录。

## 双击安装

- Windows：双击插件文件夹内的 **`Install-Plugin.cmd`**。软件安装在其他位置时，也可把那个完整文件夹拖到此文件上。
- macOS：双击 **`Install-Plugin.command`**。首次打开脚本可按 macOS 的提示，通过 Finder 右键“打开”运行。

工具自动定位完整软件和 Codex，复用自带 Node.js，绑定配置并注册插件。已有工作目录优先沿用；首次没有配置时使用 `Documents/Codex-Mobile-Workspace`。不需要 npm 或管理员权限，也无需手动添加插件市场。

安装只运行命令，不模拟鼠标键盘、不切换或操作 Codex 窗口，不弹出软件网页、登录窗口或启动助手后台。双击时打开的终端仅显示安装结果；不会强制重启 Codex。

安装结果保存在插件数据目录的 `install-result.txt`：Windows 默认 `%LOCALAPPDATA%\CodexMobile\plugin\install-result.txt`，macOS 默认 `~/Library/Application Support/CodexMobile/plugin/install-result.txt`。已有自定义插件数据目录时会沿用该目录。窗口退出后可以自行查看这个文件，工具不会弹窗或等待按键。

## 开始使用

安装完成后自行打开 Codex，进入“插件 → Codex 移动助手”，点击“打开插件”。Codex 原本已打开时，可关闭再启用本插件；若仍未显示，再自行重开 Codex。后台在打开插件页面时启动或复用。

电脑端登录 Codex 后，生成局域网或互联网二维码，手机扫码，在当前插件页面点击“批准连接”。权限、帮助、更新和关于仍在原来的六个栏目。具体功能见 [V1.3 插件使用教学](V1.3.0-PLUGIN-GUIDE.md)。

## 找不到软件或安装失败

先确认两个 ZIP 均已完整解压，并把插件文件夹放在完整软件文件夹旁。工具只查找已有配置和有限的常见位置，不会扫描整个硬盘。检测到多个候选时会提示指定目录，避免绑定到错误的软件。

Windows 可以拖软件文件夹到 `Install-Plugin.cmd`；也保留手动指定方式：

```powershell
.\Install-Plugin.ps1 -InstallationRoot 'D:\Apps\Codex-Mobile' -DefaultCwd 'D:\Projects\MyProject' -Register
```

macOS 可手动运行：

```bash
bash ./Install-Plugin.command '/Users/you/Applications/Codex-Mobile' --default-cwd '/Users/you/Projects/MyProject' --register
```

上述显式参数方式保留原手动安装行为：不带注册参数时仅绑定，带注册参数时还会注册并启动后台。双击的一键模式只完成安装注册，等打开插件页面时再启动后台。

如果提示没有找到 Codex，先安装 Codex，再重试；安装器不会替你下载另一个 Codex 或弹出账号登录。升级中的宿主缓存暂时被占用时，自行关闭插件后重试即可，安装器不会强行结束用户进程。
