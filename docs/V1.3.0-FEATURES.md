# V1.3.0：分区与 Codex 插件

手机按电脑侧栏的真实分区、项目和聊天显示列表，保留分区顺序与独立聊天。点击分区标题或项目标题可以折叠，手机会分别记住 Codex 和 GPT 的展开状态；点击刷新可重新同步电脑调整后的分区。

独立软件继续提供电脑管理网页和手机网页。插件使用相同的后台服务与配对设置，在 Codex 内提供连接手机、设备管理、手机权限、使用说明、更新与关于页面。插件安装需要先有对应平台的完整软件包，因为后台仍需本机 Node.js 与网络连接组件。

软件与插件分别显示版本和更新状态。软件升级会重启后台服务；插件升级更新插件文件，需要宿主重新加载时明确显示待生效。正在打开的页面与已经安装的文件可能暂时不是同一版本，应以页面显示的运行版本和待重新加载提示为准。

自动安装默认关闭。开启后，更新器检查更高版本，任务或审批繁忙时等待，校验下载内容后安装；本地权限、设备配对、附件和项目不作为更新文件覆盖。软件升级可能使互联网临时地址变化。

V1.2 的 GPT 续聊、Codex 附件、项目文件、消息回执、模型及思考强度、运行中引导等保持可用。手机停止和审批仍取决于当前聊天连接能力，原桌面聊天仍需在电脑处理其不支持的操作。详见 [V1.2 功能范围](V1.2.0-FEATURES.md)。

插件安装与配置见发布包内的插件 README；独立软件首次使用方法继续见对应平台 README。历史更新说明保留在各版本文档与根目录 CHANGELOG。
