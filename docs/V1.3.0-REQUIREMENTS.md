# V1.3.0 已确认范围与验收要求

本次从已发布的 Editions V1.2.0 开发，保留原有独立软件与手机网页使用方式。历史更新日志、已发布标签、Release 和用户数据不重写。

- 手机侧栏按桌面真实的“分区 → 项目 → 聊天”排列，保留名称、顺序、混排项目与独立聊天，避免重复和遗漏；空自定义分区仍可见。手机分别记忆分区和项目折叠，Codex 与 GPT 的选择和折叠互不干扰。手动刷新重新获取桌面结构。
- 提供 Windows 11、Windows 10 和 macOS 独立软件，以及 Codex 插件。插件直接在 Codex 内展示管理页面，不能以打开外部管理网页代替。手机仍使用原来的浏览器界面。
- 插件内包含连接手机、配对二维码、设备批准与撤销、手机权限、使用说明、更新与关于。沿用桌面登录，不新增 API 密钥或第二次账号登录。
- 支持插件详情页直接打开连接与二维码面板、插件页直接设置，以及对话调用三种入口；点击插件的打开入口不能以新建聊天代替管理页面。更新报告附安装、绑定、配对、权限和自动更新教学。
- 插件使用蓝色主色，布局参考原网页并沿用原图标；网页保持既有视觉样式，只增加分区显示。扫码后在当前插件页面直接显示待授权设备和批准按钮，无需切换至设备栏目。
- 软件与插件复用同一安装目录和后台服务，设置、设备配对、附件及项目数据保持一致；切换入口不重复启动服务。插件启动后台时不弹出管理网页。
- 插件自身支持检查更新、一键更新和自动更新，更新范围包括插件页面、代码和清单。清楚显示正在运行、已安装、最新和待重新加载版本，不把后台软件更新当作插件更新。
- 软件和插件的自动安装默认关闭；开启后自动检查，任务或审批未结束时等待。安装前校验来源、路径及文件哈希，失败保留或恢复可用版本。需要 Codex 重新加载时明确提示。
- 保留 Codex/GPT 聊天、项目文件、附件与原图、消息回执、模型及思考强度、运行中引导、已支持的停止和审批、外观、说明、反馈、赞助、版本公告等原有功能。桌面接口现有能力限制不因插件化而扩大。

验收包括三平台代码与启动检查、手机窄屏交互、真实 V1.2.0 到 V1.3.0 的自动安装和重启、配对及本地数据保留、插件协议与页面测试，以及当前 Codex 内的实际插件页面和插件更新。模拟网络或宿主时注明范围，不能代替实际宿主验证。验证通过后发布 GitHub 新版本和校验文件，保持旧发布不变。
