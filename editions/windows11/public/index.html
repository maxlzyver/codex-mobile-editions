从电脑到手机，只需三步

电脑是执行端，手机浏览器是你的控制台。

  1. 1

    在 Windows 11 电脑上启动

    打开并登录 Codex 桌面端，再启动 Windows 11 专用版移动助手，选择工作目录。使用期间保持电脑开机、联网。

  2. 2

    连接手机，并在电脑上确认

    点击「连接手机」。同一网络选择 Wi-Fi；其他网络选择互联网。手机扫码、填写设备名称后，在电脑端批准该设备。

  3. 3

    选聊天，发指令，看结果

    从任务列表打开聊天，选择模型与思考强度，发送指令。点击聊天中的文件链接可直接预览或下载；也可从「电脑项目与文件」浏览工作成果。

同一个聊天，取决于连接方式

连接桌面端后，可在手机继续受支持的桌面聊天。若界面提示独立模式，请按当前聊天的能力提示操作；部分审批、停止及桌面专有功能仍需回电脑完成。

常见问题

手机连不上，先检查什么？

确认电脑和移动助手正在运行，Wi-Fi 模式下两台设备应处于同一局域网。二维码过期后在电脑刷新；换网络可使用互联网模式。设备被撤销后需要重新配对。

为什么模型列表或功能与桌面不同？

模型列表由当前 Codex 连接返回，并受到版本、账户与当前聊天的支持能力影响。可点击模型区域的刷新按钮重载。界面会标明当前聊天可用的操作。

自动更新会中断正在执行的任务吗？

更新由电脑端管理。自动更新会等待任务空闲后应用；安装期间网页可能短暂断开，完成后刷新页面。也可以关闭自动更新，手动检查和安装。本版仅从 GitHub 的 editions/windows11 目录检查更新，不会安装其他平台的版本。
