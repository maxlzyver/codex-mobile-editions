# Codex 移动助手 · Windows 11 专用版 V1.3.0

版本：**1.3.0** · 作者：[maxlzyver](https://github.com/maxlzyver) · [项目仓库](https://github.com/maxlzyver/codex-mobile-editions) · [反馈邮件](mailto:lzyuan666666@gmail.com)

在手机浏览器查看电脑 Codex 的任务、发送指令、选择模型和思考强度，并预览、下载本地项目文件。支持同一 Wi-Fi 配对，以及 Cloudflare 临时互联网连接。主题、字号、字体种类、主色和文字颜色可在“设置”调整；赞助自愿，不影响功能使用。

这是独立社区工具。手机沿用电脑已登录的 Codex，无需再次输入 OpenAI 账号或 API 密钥；首次连接仍需扫码并由电脑批准。

## 本版适用范围

当前版本为 **V1.3.0**，保留此前全部功能；重点验证 1.2 的后续自动升级，更早版本无法更新时见 [升级说明](docs/V1.2.0-UPGRADE.md)。[新版下载](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.3.0)。

- 仅适用于 **Windows 11、系统内部版本 22000 或更新、原生 AMD64/x64**。拒绝 ARM64（包括 x64 模拟运行）和 32 位系统，也不会安装其他平台专用版。
- 完整包为 **`codex-mobile-windows11-1.3.0-x64.zip`**，内置 Windows x64 Node.js 24 和 cloudflared；Codex 程序及账户不包含在内，需在目标电脑自行安装并登录兼容版本。
- 手机使用支持现代 JavaScript 和 Cookie 的浏览器，无需安装本工具的手机 App。
- 电脑必须开机、联网、不休眠，移动助手后台必须运行；继续原桌面聊天还需兼容的 Codex 桌面端保持运行。

V1.0.0 基线已在本机 Windows 11（内部版本 26200，原生 AMD64）运行 `--check`，平台、Node.js 24、Codex 发现、文件与版本清单检查通过，退出码为 0。尚未在其他 Windows 11 设备或全部系统版本验证。

V1.0.0 的两个 Windows 启动器共有 **72 个平台边界断言**通过，包括 19044、19045、21999、22000 等版本边界，以及 AMD64、x86、ARM、ARM64 的区分。平台策略测试不等同于在对应系统上的完整运行测试。更多边界见 [兼容性说明](docs/COMPATIBILITY.md)。

## 第一次使用

1. 将本版完整 ZIP 解压到当前用户可读写的文件夹。不要在压缩包内运行，也不要只复制 EXE。
2. 在目标电脑安装并登录兼容的 Codex。希望继续桌面原聊天时，同时打开兼容的 Codex 桌面端。Windows 10 上须自行确认所用 Codex 版本支持该系统；本工具不会使不兼容的官方程序变得兼容。
3. 双击 **`Codex-Mobile.exe`**，首次选择自己的项目目录。后台服务准备好后，会打开电脑管理页面。
4. 点击 **“连接手机”**。同一局域网选择 Wi-Fi；跨网络选择互联网并等待连接成功。
5. 手机扫码、在浏览器打开链接并填写设备名称，再回电脑页面批准该设备。
6. 打开任务列表，选择聊天并发出指令；输入框上方可以选择项目、模型和思考强度。“电脑项目与文件”提供文件浏览、预览及下载。

配对码有效 **2 分钟**，一次使用后失效；待批准申请有效 5 分钟。获批浏览器的设备授权有效 30 天，并可由电脑随时撤销。清除 Cookie、更换浏览器或入口地址、授权过期后需要重新配对。电脑 Codex 登录失效时，也需要在电脑重新登录。

关闭网页不会停止任务。从系统托盘选择退出，或双击 **`Stop.cmd`**，可正常停止本目录的助手和它创建的子进程；不会关闭原有 Codex 桌面应用。`Start.cmd` 是备用入口，它同样调用本版原生启动器并执行平台检查。

## 旧版本首次换装与分发

Windows 10、Windows 11、macOS 三个专用版均从 **V1.0 / 1.0.0** 重新开始版本序列，并迁往新仓库。旧通用版 **1.2 不会自动降级或迁移**到本专用版。

首次换装请先退出旧移动助手，把与你系统匹配的完整专用版解压到**新文件夹**，重新选择工作目录、配对手机。原电脑的 Codex 聊天和项目文件仍留在原位置；手机端能否继续具体聊天，以界面显示的连接能力为准。不要用旧版程序文件覆盖新版，也不要把旧版 `.runtime` 整目录覆盖过去。

给其他人使用时，只分发打包工具生成的干净 ZIP。不要上传或分享使用后的整个目录：`.runtime`、账户登录信息、配对 Cookie、管理链接、聊天和项目文件均为私人数据。每台电脑使用自己的 Codex 安装和登录。EXE 未提供代码签名，下载完整性可通过发布时提供的 SHA256 校验值核对。

## 任务和文件能力

- **桌面原聊天：** 当界面标明“桌面原会话”时，可查看进度并把后续指令发送到同一聊天；按当前接口能力选择模型、思考强度或在运行中引导。此连接使用 Codex 本地内部接口，可能随桌面版本变化；不是稳定公开 API。原生聊天的审批和强制停止仍需在电脑处理，桌面插件窗口不会复制到网页。
- **新建任务与子聊天：** “新建任务”使用助手独立的 Codex 连接，可在网页继续、引导、停止及处理支持的审批；它共享电脑文件和账户，但不继承原桌面聊天的专有工具环境。桌面项目下的“新建子聊天”使用桌面接口，仍属于原桌面聊天，停止和审批需在电脑完成。
- **历史与分支：** 原生接口不可用时，桌面历史只读；可用“在此继续分支”保留上下文继续工作，分支不是原聊天。原生发送超时不会换一个连接自动补发，避免重复执行。
- **模型：** Codex 从本机账户动态获取模型与思考强度；GPT 沿用电脑当前聊天的模型，需在电脑切换。选择“沿用默认／当前会话”时不覆盖已有设置；当前聊天不支持的操作会提示。
- **项目与文件范围：** 聊天列表按桌面返回的真实项目及聊天归属展示。文件页汇总默认目录和最多 5000 个非归档聊天的工作目录，电脑端可添加其他已有目录；添加文件目录不会创建桌面项目。手机浏览的是电脑真实文件。
- **预览与下载：** UTF-8 文本／代码预览上限 1 MiB；图片直接查看，PDF 在浏览器新标签页阅读；其他格式可下载。支持单文件和字节范围下载，不支持文件夹整体打包。

## 设置、自动更新与反馈

“设置”含外观、使用说明、更新与关于。外观保存在当前浏览器，各设备可不同。外观和公式使用本机字体，公式通过浏览器 MathML 显示，不从第三方字体服务加载。“赞助一下”展示作者原始微信收款码，支持打开原图和保存；不会自动发起支付。反馈链接仅打开用户自己的邮件程序，不会自动发送邮件或上传日志。

本版更新源唯一固定为 **`maxlzyver/codex-mobile-editions` 的 main 分支 `editions/windows11/update.json`**。更新器固定 Git 提交并校验清单和文件哈希；不会改读其他专用版、旧仓库、仓库根目录的清单，也不会回退到旧 Releases。作者应上传该平台程序文件及同次生成的清单。没有本版清单时显示未发布状态，不会误报已是最新版。

只有电脑管理端可检查、安装及配置自动更新；手机可查看状态。自动更新默认关闭，开启后定期检查，等待任务和审批空闲后应用。手动安装遇到忙碌状态，可在任务结束后点击“重新尝试安装”。更新会重启助手，保留本地运行配置和项目目录；临时互联网入口可能变化。

本专用版以后只接收自身版本序列中的更高版本。发布入口、目录与打包规则见 [发布说明](docs/RELEASING.md)。

## 与官方 ChatGPT App 的区别

官方 ChatGPT App 也有 Codex 移动／电脑远程连接入口，可用性取决于功能开放、账户和工作区设置。本工具的特点是 **Windows 11 自托管、手机浏览器访问、本地项目文件预览下载、外观自定义**，而非官方完全不能控制电脑。

本工具不增加模型权限或账户额度，也不替代全部桌面功能。官方说明：[Codex on mobile](https://learn.chatgpt.com/docs/mobile)。

## 网络、访问和运行数据

同一 Wi-Fi 模式使用局域网 HTTP，请选择可信网络。Windows 防火墙、访客 Wi-Fi 或设备隔离可能阻止访问；程序不会自动修改防火墙规则。

互联网模式使用 Cloudflare Quick Tunnel，流量经过 Cloudflare，电脑需保持出站网络可用。地址会随连接重建变化；临时隧道没有本工具可承诺的持续可用性，部分网络可能无法访问。无需端口转发，也不会注册系统服务。

手机必须经一次性配对和电脑批准，写入请求检查身份、来源和 CSRF。文件访问限制在已知项目根目录，并拒绝越界链接、账户凭证目录和助手私有运行目录。配对权限不会替代 Codex 本身的命令审批。

不要公开 `.runtime`、管理链接、二维码或浏览器 Cookie。该目录包含设备授权、管理入口和助手任务索引；聊天本体由本机 Codex 保存。程序以当前 Windows 用户身份运行，访问权限也依赖目标文件夹的 Windows 权限。

## 高级选项和验证

启动前可设置：`CODEX_BINARY` 指向 Codex EXE，`CODEX_MOBILE_CWD` 指向独立且已存在的项目目录，`CODEX_MOBILE_PORT` 设置服务端口。显式 `CODEX_BINARY` 优先，错误路径不会被其他发现结果覆盖。启动器优先使用随包 Node.js 24；它不下载 Codex，不自动提权。

无需打开界面的环境检查：

```powershell
.\Launch.ps1 -Check
```

结果写入本机 `.runtime/check.json`，不包含账户内容。开发者可在程序目录运行测试：

```powershell
.\runtime\node.exe --test test/*.test.mjs
```

V1.0.0 基线在当时的 Windows 11 主机运行两版各自的核心套件（不含单独维护的更新器／安装器套件），**每版 96 项全部通过**。这些测试使用模拟连接与临时目录，不代表 Windows 10 实机运行通过。自动化测试覆盖协议、任务、模型、项目路径保护、手机权限和本地桌面适配。原生发送使用模拟接口验证参数与错误处理，不能据此宣称每个桌面版本都已真实端到端发送成功；该次验证没有向用户现有聊天发送测试指令。不同设备及真实手机 4G/5G 连通性需在目标环境确认。

V1.2.0 本次回归结果见对应发布记录和 [Actions](https://github.com/maxlzyver/codex-mobile-editions/actions)，不以既有测试结果代替新版验证。
