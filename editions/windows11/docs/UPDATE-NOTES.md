V1.1.0 · 加载优化与新图标

- 优先显示近期用户消息与最终答复，再在后台补齐更早历史和执行详情。
- 已打开过的聊天使用有界内存缓存，返回时先显示上次内容，再同步最新进展；退出或撤销授权后清空。
- 折叠过程和工具正文在展开时才生成，减少长执行记录对手机显示的影响；过程数据仍可后台预加载。
- 只重绘变化的消息，空闲时降低刷新频率，未变化的数据使用版本校验减少传输；后台补齐时保持阅读位置。
- 更换为作者提供的新图标，应用于网页、手机添加到主屏幕以及 Windows 启动器与托盘。
- 保留原有文件预览下载、发送回执、模型选择、整轮折叠、手机权限、配对、外观、反馈与赞助。
- 继续在启动后及每 6 小时检查更新，显示新版说明；可选择本版本不再提示，直到下次更新，自动安装仍默认关闭。

Windows 11、Windows 10、macOS 专用版统一升至 1.1.0。1.0.0 和 1.0.1 专用版可通过原有更新入口升级；更新保留 .runtime、电脑项目与 Codex 聊天。本版未加入 GPT 模式或新的账号登录入口。
