# 从 V1.2 升级至 V1.3

已安装 Editions V1.2.0 的用户，可继续在电脑管理端检查并安装更新，或开启自动更新。自动更新会在后台检查，等待任务与审批空闲，再下载校验、安装和重启。升级保留原来的运行组件、设备配对、权限、附件及项目。

手机首次载入 V1.3 后，侧栏显示电脑的真实分区；原有聊天和项目不迁移、不重建。电脑调整分区后可在手机手动刷新。

插件是新增入口，需要单独安装一次。安装时选择现有 V1.3 软件目录和默认项目目录，之后软件网页与 Codex 内插件面板管理同一个服务。插件自动更新与软件自动更新各有开关，不会因安装插件而自动启用。

新安装用户仍需下载对应系统的完整 ZIP；GitHub 自动生成的源码 ZIP 不包含运行组件。更早版本的换装说明继续见 [V1.2 升级说明](V1.2.0-UPGRADE.md)。不要删除已安装目录的 `.runtime`，其中保存本机配置和设备配对；不要把该目录上传 GitHub。
