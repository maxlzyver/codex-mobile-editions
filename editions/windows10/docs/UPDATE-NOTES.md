V1.3.0 · 分区显示与 Codex 插件

- 手机按桌面真实分区、项目与聊天显示，保留顺序、独立聊天与空自定义分区；分别记忆 Codex/GPT 的折叠状态，手动刷新同步调整。
- 新增 Codex 内嵌插件入口，包含连接手机、设备管理、手机权限、使用说明、更新与关于；独立软件和网页继续可用。
- 软件与插件共享同一后台服务、配置和配对；插件启动后台时不弹出管理网页。
- 插件自身支持检查更新、一键更新和自动更新，区分运行、安装、最新与待重新加载状态；自动安装默认关闭，任务繁忙时等待。
- 保留 V1.2 的 GPT 文字续聊、Codex 附件与原图、文件浏览下载、消息回执、模型与思考强度、运行中引导、支持的停止与审批、外观设置、反馈和赞助。
- 保留软件启动后及每 6 小时的更新检查、版本说明和“下次更新前不再提示”（仅本版本不再提示）；关闭自动安装仍会提醒新版。

三种专用版统一为 1.3.0。V1.2 用户沿用原更新入口；本地运行组件、配对、权限与项目保持保留。插件首次使用需要单独安装。桌面原聊天的停止与审批仍受接口能力限制。

插件使用教学

1. 下载对应系统的 V1.3 完整软件包和 codex-mobile-plugin-1.3.0.zip，分别完整解压；已有 1.3 软件的用户直接使用现有软件目录。
2. Windows 在插件目录打开 PowerShell，运行 .\Install-Plugin.ps1 -InstallationRoot '软件目录绝对路径' -DefaultCwd '已有项目目录绝对路径' -Register。macOS 在插件目录运行 bash ./Install-Plugin.command '软件目录绝对路径' --default-cwd '已有项目目录绝对路径' --register。把示例路径换成自己的实际目录。
3. 在 Codex 的插件入口打开“Codex 移动助手”，或要求“打开移动助手管理面板”，点击“启动助手”。后台已有服务会被复用，不必打开软件管理网页。
4. 同一 Wi-Fi 下生成局域网二维码；外网使用时先开启互联网连接，再生成外网二维码。手机扫码后，到“设备”批准连接。二维码两分钟有效且仅用一次。
5. “手机权限”内分别控制审批、停止任务及访问其他目录，设置与软件共用。原桌面聊天操作仍受 Codex 接口限制。
6. “更新”内分别检查插件和后台的新版本，点击对应的一键更新按钮；需要自动安装时开启相应开关，默认关闭。任务繁忙时等待空闲。
7. 插件显示运行、已安装、最新三个版本。出现“待 Codex 重新加载”时按提示重新加载插件，必要时结束手头工作后重新打开 Codex，再核对运行版本。后台更新可能改变互联网临时地址，但保留配对和权限。
8. 使用说明、连接诊断与关于信息均在插件面板内。详细步骤见发布包 docs/V1.3.0-PLUGIN-GUIDE.md；独立软件启动入口保持可用。
