# V1.3 插件使用教学

插件将电脑管理页面放进 Codex。手机仍使用浏览器，软件版也可以继续独立使用；两种入口共用配对、权限和后台服务。

## 1. 下载并解压

从 V1.3 Release 下载与你电脑相符的完整软件 ZIP，以及 `codex-mobile-plugin-1.3.0.zip`。两者都要完整解压到当前用户可写的位置。已经通过自动更新升到 1.3 的用户直接使用现有软件目录，再下载插件包即可。

软件目录应能看到 `edition.json`、`server.mjs` 和 `runtime`；插件目录应能看到 `Install-Plugin.ps1` 或 `Install-Plugin.command`。插件复用软件包里的运行组件，用户无需安装 npm。电脑须已安装并登录 Codex。

## 2. 安装并绑定现有软件

Windows：在解压后的插件目录打开 PowerShell，把下面两个示例路径换成自己的软件目录、已有项目目录，然后运行：

```powershell
.\Install-Plugin.ps1 -InstallationRoot 'D:\Apps\Codex-Mobile' -DefaultCwd 'D:\Projects\MyProject' -Register
```

macOS：在解压后的插件目录打开终端，替换路径并运行：

```bash
bash ./Install-Plugin.command '/Users/you/Applications/Codex-Mobile' --default-cwd '/Users/you/Projects/MyProject' --register
```

已有软件默认项目配置时可省略 `DefaultCwd`。项目目录要事先存在，不能选磁盘根目录或软件自身目录。注册成功后，在 Codex 的插件列表中可找到“Codex 移动助手”。安装工具会输出绑定结果和本地插件源位置；如注册没有完成，按工具提示检查 Codex 路径后重新运行。

## 3. 打开 Codex 内页面

在 Codex 的插件入口打开“Codex 移动助手”，或在聊天中要求“打开移动助手管理面板”。进入内嵌页面后点击“启动助手”：已有服务会被复用，未启动时会在后台启动，不必打开软件管理网页。

面板提供“手机连接、设备、手机权限、使用说明、更新、关于”。关闭面板不会停止后台服务或中断手机连接。

## 4. 连接手机

同一 Wi-Fi：在“手机连接”生成局域网二维码，用手机扫码；回到“设备”批准这台手机。互联网：先开启互联网连接，连接成功后生成外网二维码，再扫码并批准。二维码两分钟内有效且只能使用一次，过期后重新生成。

手机沿用电脑的 Codex 登录，不需要再输入账号或 API 密钥。电脑要持续开机、联网且不休眠。撤销设备后，该手机需要重新配对。

## 5. 设置手机权限

“手机权限”内分别设置处理任务审批、停止任务和访问其他本机目录。它们与软件版设置同步，首次安装默认关闭；升级保留已有设置。访问其他目录不会改变 Codex 的沙箱或执行权限。原桌面聊天能否停止或审批仍取决于当前桌面接口。

## 6. 更新插件和后台

进入“更新”，可分别看到“插件更新”和“助手后台更新”。点击“检查更新”查看可用版本，再点击对应的一键更新按钮；如希望自动安装，开启相应的自动更新开关。两个开关独立，默认关闭，任务或审批繁忙时等待空闲。

插件更新覆盖插件代码、内嵌页面、Skill 与清单。留意三个版本：“运行版本”是当前会话加载的版本，“已安装版本”是已经写入本机的版本，“最新版本”是检查到的发布版本。如果显示“待 Codex 重新加载”，按提示重新加载插件，必要时在结束手头聊天后重新打开 Codex；回来确认运行版本已变为目标版本。更新器不会强制关闭 Codex。

后台更新会重启助手，手机短暂断线后重新连接；互联网临时地址可能变化。权限、配对、附件与项目保持保留。失败时查看页面提示，可在“使用说明”运行诊断。

## 7. 两种模式之间切换

需要独立软件时继续运行原来的 Windows EXE 或 macOS `Start.command`；需要 Codex 内管理时打开插件。绑定同一软件目录即可共享后台，避免另外解压并启动第二份服务。不要删除原软件目录，也不要把其中的 `.runtime` 上传或分享给别人。
