# Windows 10 专用版 V1.0：兼容性与运行边界

版本 1.0.0，作者 maxlzyver，仓库 [maxlzyver/codex-mobile-editions](https://github.com/maxlzyver/codex-mobile-editions)。本版目录固定为 `editions/windows10`，不能与其他平台文件混用。

## 平台与已验证范围

| 项目 | 要求与边界 |
| --- | --- |
| 系统 | Windows 10 22H2、系统内部版本 19045–21999、原生 AMD64/x64。不接受 ARM64、ARM、x86 或其他平台。 |
| 原生架构 | 启动器调用 GetNativeSystemInfo；ARM64 上的 x64 模拟进程仍按 ARM64 拒绝。不是仅检查 Is64BitOperatingSystem。 |
| 运行时 | 便携包附带 Windows x64 Node.js 24；源码运行至少需要 Node.js 24。 |
| Codex | 目标电脑自行安装并登录支持 app-server 的兼容 Codex。尤其不能因本助手支持 Windows 10 就推断所有官方 Codex 桌面版本都支持 Windows 10。 |
| 手机 | 支持现代 JavaScript、Cookie 的浏览器；扫码、下载及后台保活能力随浏览器变化。 |
| 状态 | 电脑开机、联网、不休眠，助手后台运行；使用原桌面聊天还要保持兼容桌面端运行。 |
| 安装目录 | 当前用户可写的完整解压目录；项目目录应独立于程序目录。 |

**尚未在真实 Windows 10 设备运行验证。** 当前开发机为 Windows 11（内部版本 26200），本版 `--check` 按预期返回不支持，退出码为 1；依赖、文件及版本清单检查通过。这不能代替 Windows 10 实机测试。

两个 Windows 启动器共通过 72 个平台策略断言，每版 36 个。包含 19045 / 22000 两个关键边界及 ARM64 模拟场景。这里验证的是纯判断函数和当前主机的无界面检查，**不代表真实 Windows 10、其他 Windows 11 版本或全部网络的实机兼容性**。

两版各自的核心自动化套件（排除单独维护的更新器／安装器套件）均在当前 Windows 11 主机通过 96 项测试，使用模拟接口与临时目录。测试目录位于工作区 work，不写入可分发的程序目录。

网页在 Chrome 的 390px 与 320px 宽度、22px 字号下进行了本版品牌、关于、新仓库链接和赞助图验证。浏览器模拟尺寸不等于所有真实手机的测试。

## Codex 原生连接

助手可尝试复用共享 Codex 连接，不可用时启动自己的 app-server。它还通过当前用户的本地桌面内部接口读取／继续受支持的原聊天，不修改 Codex 安装，不为接入而重启桌面。

- 仅处理当前电脑 local 聊天，不控制其他主机或 ChatGPT 云端聊天。
- 原生后续指令保持目标聊天编号，但内部接口的消息来源标记可能与手动在桌面输入不同。
- 原生聊天的审批与强制停止仍在电脑处理；不伪装为支持。桌面专有插件和窗口也不会完整镜像。
- 原生接口缺失、关闭或读取失败时显示只读历史；可继续分支，但分支不是原聊天。
- 原生发送失败或超时不会切换到另一连接自动补发。超时可能发生在桌面已接受指令之后，先查看状态再决定是否重发。
- 助手自行创建的任务可在网页处理受支持的审批与停止，共享文件与账户，不继承原桌面聊天的专有工具环境。

内部桌面接口不是稳定公开 API。自动化测试对原生写入参数和失败路径采用模拟接口，本轮没有向真实用户聊天发送测试指令。

## 文件和权限

项目来自默认目录、最多 5000 个非归档聊天目录和电脑端额外添加目录。访问检查真实路径与根目录边界，阻止越界、Windows ADS、保留文件名、账户凭证目录和助手运行状态目录。

UTF-8 文本预览最多 1 MiB；HTML/SVG 作为文本或附件，PDF 打开浏览器阅读器，普通图片直接预览。大文件下载采用流传输和单一字节范围请求。不是整盘远程文件管理器，也不是聊天备份工具。

手机经电脑批准后可读取项目结果和下达任务；请仅批准自己信任的设备。二维码 2 分钟一次性，待批准申请 5 分钟，设备授权 30 天；电脑端可随时撤销。配对权限不代替 Codex 自身的审批。

## 网络、进程和停止

服务监听本机局域网端口；管理页面通过 127.0.0.1 打开。默认端口为 43127，启动器可在默认端口被占用时选择后续可用端口；显式指定端口已占用时会报错，不接管其他程序。

Wi-Fi 使用 HTTP，访客隔离、VPN、防火墙或路由规则可能阻断。互联网模式通过 Cloudflare Quick Tunnel 提供临时 HTTPS 入口；流量经过 Cloudflare，地址可能随重连变化，某些网络不可达。程序不会自动修改防火墙或注册 Windows 服务。

关闭浏览器不停止任务。使用托盘退出或 Stop.cmd 正常停止本助手；脚本委托本版 EXE 验证本目录、PID／启动时间、回环地址及 owner 身份，再发送正常关闭请求，不关闭原有 Codex 桌面程序。断电、注销或强制结束进程不能保证完整清理。

## 更新、迁移和私有数据

仅从 `maxlzyver/codex-mobile-editions` main 分支的 `editions/windows10/update.json` 检查更新。固定 Git 提交、核对 edition／platform／version 并校验文件 SHA256；不会回退到旧仓库、旧 Releases 或其他平台目录。哈希校验用于下载一致性，不等同于代码签名或独立安全认证。

更新只由本机管理端执行，自动更新默认关闭；任务与审批空闲后安装。安装器限制解压与覆盖路径，备份程序文件并尝试在失败后恢复，保留运行配置和项目。测试中的模拟／临时目录安装不能代替每台目标机器的真实升级验收。

旧通用版 1.2 需首次手动换装到新目录。本专用版从 1.0.0 开始，不会通过版本比较自动降级旧版。新仓库只能包含干净程序，禁止上传 `.runtime`、配对信息、账号登录文件、聊天、项目和测试日志。Windows 的文件访问还依赖 NTFS 权限，Unix mode 参数不能替代 Windows ACL。

外观保存在当前浏览器；反馈只打开邮件程序；赞助展示原始静态收款码，不自动发送邮件、上传日志或发起支付。
