# Codex 移动助手 · macOS 专用版 V1.3.1

版本 **1.3.1** · 作者：[maxlzyver](https://github.com/maxlzyver) · [项目仓库](https://github.com/maxlzyver/codex-mobile-editions) · [邮件反馈](mailto:lzyuan666666@gmail.com)

用手机浏览器查看 Mac 上 Codex 的任务与输出、选择模型和思考强度、远程发送指令，并预览和下载本地项目文件。支持 Wi-Fi 配对、互联网临时连接、主题字体设置、分平台自动更新和自愿赞助入口。

## 系统与安装

当前版本为 **V1.3.1**，保留此前全部功能；重点验证 1.2 的后续自动升级，更早版本无法更新时见 [升级说明](docs/V1.2.0-UPGRADE.md)。[新版下载](https://github.com/maxlzyver/codex-mobile-editions/releases/tag/v1.3.1-full)。

- **macOS 14 或更新版本**，Apple 芯片或 Intel。完整包 `codex-mobile-macos-1.3.1-universal.zip` 包含两套 Node.js 24 和 cloudflared，按机器架构选择。
- Mac 需自行安装并登录兼容的 Codex 桌面应用或 CLI；包内不包含 Codex 程序和账户。
- 完整解压到当前用户可写目录，保持目录结构。不能使用 GitHub 自动生成的 Source code ZIP 代替完整安装包。

## 第一次使用

1. 在 Mac 安装并登录 Codex。需要登录 CLI 时可双击 **Login.command**，它在终端运行本机 Codex 的登录流程。
2. 双击 **Start.command**，首次选择项目工作目录。服务准备好后自动打开电脑管理网页。未签名脚本可能需要 Finder 右键打开并按系统提示批准；不需要关闭系统安全功能。
3. 点击“连接手机”，选择同一 Wi-Fi 或互联网连接。手机扫码打开链接并提交设备名称，再回电脑批准。
4. 手机上查看任务、发送指令、选择模型，或进入“电脑项目与文件”浏览、预览和下载。
5. 启动成功后可关闭终端和网页，助手仍在后台运行。双击 **Stop.command** 可停止本安装的助手；不会停止原有 Codex 桌面应用。

重新选择工作目录可在终端运行 `./Start.command --configure`。程序按当前 Mac 用户运行，不安装系统服务，不要求管理员权限。Mac 必须开机、联网且不休眠，后台助手须保持运行。

首次配对码有效 2 分钟且只能用一次，待批准请求有效 5 分钟。手机浏览器获批后授权有效 30 天，可由电脑撤销。手机复用电脑的登录；清除 Cookie、地址变化、授权或 Codex 登录过期后，需要重新配对或登录。

## 聊天与文件

兼容的 Codex 桌面接口存在时可继续原桌面聊天，并按接口能力选择模型、思考强度或在运行中引导；程序仅尝试当前用户拥有的可信本地 Unix socket。找不到接口时显示只读历史，仍可使用助手自己的 Codex 新建任务或从历史继续分支。分支不等于原聊天，原桌面聊天的审批和强制停止需在电脑处理。内部接口随 Codex 升级可能改变；本版不承诺所有桌面版本都可原聊天发送。

“新建任务”使用助手独立连接，可以在网页继续、引导、停止及处理支持的审批。Codex 模型与思考强度来自当前账户，不增加账户额度或权限，也不继承全部桌面专有工具。桌面项目下的“新建子聊天”使用原桌面接口，停止与审批仍需在电脑完成。GPT 支持已有聊天的文字读写，沿用电脑聊天中的模型。

文件页访问真实项目目录，可预览 UTF-8 文本／代码（最多 1 MiB）、图片和 PDF，并下载单个文件。电脑可添加其他项目目录。访问限制在已知项目根目录，拒绝越界链接和私有凭据目录；没有文件夹整体打包功能。

## 设置与更新

设置提供主题、字体种类、字号、主色、文字颜色、说明、更新、反馈与“赞助一下”。外观保存在当前浏览器；反馈仅打开邮件草稿，由用户自行发送。赞助展示原始微信二维码，可打开原图或保存，不自动支付。

更新源固定为 `maxlzyver/codex-mobile-editions` 的 `main` 分支 **`editions/macos/update.json`**。只接受本版更高版本，检查固定提交中的文件哈希与 macOS 身份，不读取 Windows 目录、旧仓库或旧 Releases。首次完整包内的运行组件在日常文件夹更新时保留。

电脑管理端可检查和安装更新、开启自动更新；手机仅查看状态。自动更新默认关闭，开启后等待任务和审批空闲再应用。更新器备份文件、替换程序并重启；失败时尝试回滚。本地配置和项目保留，临时互联网地址可能变化。发布说明见 [docs/RELEASING.md](docs/RELEASING.md)。

三个专用版均从 V1.0 开始。旧通用版 1.2 不会自动迁移到本仓库的专用版；首次换装请退出旧助手，将新包解压到新目录、重新选项目并配对。不要把旧 `.runtime` 整目录覆盖过来。

## 与 ChatGPT App 的区别

本工具是独立社区程序，侧重 Mac 自托管、手机浏览器操作、本地项目文件预览下载与外观自定义。官方 ChatGPT 移动端也可连接电脑使用 Codex，具体以账户及开放情况为准：[官方移动端说明](https://learn.chatgpt.com/docs/mobile)。这不是 OpenAI 官方客户端，也不复制全部桌面插件或权限功能。

## 网络、隐私与兼容性

Wi-Fi 模式使用局域网 HTTP，请使用可信网络。互联网模式经 Cloudflare Quick Tunnel，无需路由器端口转发，但地址会变化，部分网络可能无法访问。macOS 防火墙或本地网络权限提示需用户按实际情况允许。

不要上传使用后的程序目录：`.runtime` 存放管理入口、设备授权及运行数据，不属于公开发布内容。每台电脑使用自己的 Codex 安装和登录；账号信息不随软件分发。

V1.0.0 基线在 Windows 开发主机运行跨平台协议和独立安装器测试，Mac 启动、进程、隧道和回滚逻辑有专用测试。GitHub Actions 配置了 Apple 芯片和 Intel 的 macOS 运行器，但这些验证不等同于真实 Finder、Codex 桌面和手机网络端到端验收；没有本地 Mac 实机完整测试。详情见 [兼容性说明](docs/COMPATIBILITY.md) 和项目 Actions 结果。

V1.2.0 本次回归结果见对应发布记录和 [Actions](https://github.com/maxlzyver/codex-mobile-editions/actions)，不以既有测试结果代替新版验证。
