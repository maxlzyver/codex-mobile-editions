# V1.2 项目、GPT 与附件

手机连接的是已配对电脑的现有登录，不新增 OAuth 登录或 API Key。

| 功能 | Codex | GPT |
| --- | --- | --- |
| 查看已有聊天、发送文字 | 支持；桌面接口可用时连接原聊天 | 支持已有桌面 GPT 聊天 |
| 模型与思考强度 | 按接口提供的实际能力选择 | 沿用电脑当前聊天模型，在电脑切换 |
| 项目分类 | 使用真实项目编号与聊天归属 | 展示接口返回的 GPT 项目及聊天 |
| 新建项目内聊天 | 在已有本机 Codex 项目中创建原桌面子聊天 | 在电脑端创建 |
| 新建、重命名、删除桌面项目 | 在电脑端操作 | 在电脑端操作 |
| 运行中引导 | 支持的 Codex 聊天可继续引导 | 等待当前回复结束后发送 |
| 停止后发送 | 助手独立任务可用，须开启手机停止权限；原桌面聊天不支持 | 在电脑端停止 |
| 手机上传附件 | 支持图片及普通文件 | 当前桌面接口未开放，须在电脑添加 |

当前原桌面聊天的停止与审批须在电脑完成，包括手机在桌面项目下“新建子聊天”创建的聊天。“新建任务”使用助手独立连接，支持网页停止与审批；手机使用这些操作还需电脑授权。停止后发送会先等待实际停止，确认失败时不发送新消息。

## 文件与消息

手机可从相册或文件管理选择文件，每条最多 8 个、单个最多 25 MiB。点击发送时上传到这台电脑，附件保存在移动助手私有运行目录，随程序更新保留。普通文件由 Codex 读取本地路径；助手独立任务的图片同时传给支持的图片输入，原桌面聊天通过文件引用读取。

对话中显示文件类型、名称和可用的大小；图片显示预览并提供原图下载。新上传文件下载保持原字节，生成文件仍从授权的项目目录下载。历史附件若已被清理或不在授权目录内，页面会说明不可访问，无法凭旧聊天文字恢复丢失文件。

文件元信息和系统问答包装转换为用户正文与附件卡片。文字、代码、表格、Markdown 和数学公式采用安全渲染；原始 HTML 不执行。已读聊天缓存、近期问答优先显示、执行过程后台补载、整轮折叠等 V1.1 功能继续保留。

## 桌面接口范围

桌面接口会随官方软件版本变化，以页面显示的实际能力为准。GPT 列表当前提供置顶与最近聊天，不能据此声称已列出全部 GPT 历史；不在列表中的较早 GPT 聊天可先在电脑打开再刷新。原始账号凭据留在电脑端，不发送给手机。
