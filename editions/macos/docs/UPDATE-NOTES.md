V1.4.0 · 手机聊天与返回入口

- 手机聊天栏调为紧凑布局。项目、模型与思考强度放进输入框旁的设置按钮。弹出键盘时，聊天区会跟随手机可用高度调整。
- 已配对的手机可打开「任务列表 → 保存返回入口」，把地址加到当前浏览器的书签或主屏幕。重新打开后会继续上次的 Codex 或 GPT 聊天。
- 电脑网页和 Codex 插件的手机连接页会显示当前返回地址。电脑需要保持在线；如果局域网地址或临时外网地址变化，请在新地址重新配对。

- 新增 Android APK。手机扫码并在电脑端批准后，关闭 App、更新或切换网络仍可使用原设备绑定。换机、卸载重装、清除 App 数据或电脑端撤销后需重新扫码。
- Android 使用原生聊天和可收起的项目侧栏，支持项目文件浏览、文本预览、下载和附件发送。Android 单个上传附件上限为 8 MiB。
- 同一个互联网隧道运行期间使用同一随机 HTTPS 地址。若隧道重新生成，在原局域网重连可同步新地址，也可在 App 中手动更新地址。设备绑定随原电脑保留。
- 助手每 6 小时检查一次更新。更新提醒可以选择本版本不再提示。

插件使用教学

1. 完整解压对应系统的 1.4.0 软件 ZIP。
2. Windows 双击根目录 Install-Plugin.cmd，macOS 双击根目录 Install-Plugin.command。
3. 打开 Codex，进入「插件 → Codex 移动助手」，生成二维码。手机扫码后，在电脑上批准设备。
4. 已有配对可在同一浏览器打开返回地址。独立软件也可用 Codex-Mobile.exe 或 Start.command 启动。
