V1.3.1 · 软件包内置插件一键安装

- Windows 11、Windows 10、macOS 软件与插件统一为 1.3.1。
- 完整软件包已经包含插件和安装工具，不用另外下载插件。Windows 根目录新增 Install-Plugin.cmd；macOS 根目录新增 Install-Plugin.command。
- 双击后直接绑定所在软件目录，使用包内 Node.js 完成插件注册，无需 npm、手动输入命令或添加插件市场。
- 安装时不必提前打开 Codex，但必须已经安装 Codex。工具不模拟鼠标键盘、不操作其他窗口、不打开浏览器或登录窗口，也不会强制重启 Codex。
- 保留软件网页、蓝白插件界面、原图标、当前页批准设备、手机权限和更新功能。

插件使用教学

1. 下载与你系统对应的 1.3.1 完整软件 ZIP，完整解压到可写目录。不要在压缩包内直接运行，也不要下载 Source code 代替软件包。
2. Windows 双击软件文件夹根目录 Install-Plugin.cmd；macOS 双击同目录 Install-Plugin.command。无需先启动软件或打开 Codex。
3. 安装完成后自行打开 Codex，进入“插件 → Codex 移动助手”，点“打开插件”。Codex 已经运行时可关闭再启用本插件，必要时自行重开 Codex。
4. 确认电脑端 Codex 已登录，在插件中生成二维码。手机扫码后直接在当前插件页面点“批准连接”。设置入口可直接调整手机权限，也可以在对话中说“打开移动助手管理面板”。
5. “更新”中分别管理软件与插件的检查更新、一键更新及自动更新。自动更新默认关闭；插件安装后需要宿主重新加载时会显示待生效。

仍可使用 Codex-Mobile.exe（Windows）或 Start.command（macOS）启动独立软件。
从旧版在线更新的用户可运行 tools/Install-Plugin.cmd（Windows）或 tools/Install-Plugin.command（macOS）；完整 ZIP 的根目录也提供入口。
详细教学与故障处理见 docs/V1.3.1-PLUGIN-INSTALL.md。

安装修正

- 在线升级后首次启动会补齐根目录安装入口，已有文件保持原样。
- 修复卸载插件后旧插件源仍存在时的一键安装失败：识别并复用本插件原有有效配置，避免同名插件源冲突。
- 安装失败日志增加阶段、退出码和经过处理的错误详情，便于定位原因。
- 产品版本仍为 1.3.1；此前已经升级到同版本的用户不会再次收到自动安装，请使用修复后的完整软件包。
