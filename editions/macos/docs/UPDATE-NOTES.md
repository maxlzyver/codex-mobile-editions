V1.2.0 · 项目、GPT 聊天、附件与自动升级

- 左侧按电脑真实项目归类聊天，支持在已有 Codex 项目内新建子聊天；不按文件路径猜测项目归属。
- 新增 GPT 切换，直接复用桌面登录，查看与继续已有 GPT 聊天。GPT 沿用电脑当前聊天的模型；新建、模型切换、停止和附件发送请在电脑完成。
- 手机支持从相册或文件管理添加 Codex 附件，显示上传进度、图片预览和文件类型卡片，可下载附件与图片原图。每次最多 8 个文件，单个最多 25 MiB。
- 用户消息改为紧凑的右侧气泡；将系统问答回执和附件说明还原为实际内容。改进 Markdown、代码、表格与公式显示。
- 执行中显示状态条，可引导当前 Codex 任务；助手独立任务在权限允许时还支持停止后发送。桌面原聊天（包括手机在桌面项目中新建的子聊天）的停止仍需在电脑完成。
- 修复 Windows 更新助手提前退出的问题；1.2 开启自动更新后自动发现新版，等待任务空闲，下载、校验、安装并重启，保留本地设置和配对。
- 保留启动后及每 6 小时的更新检查、版本说明和“下次更新前不再提示”（仅本版本不再提示）；关闭自动安装仍会提醒新版。
- 保留 1.1 的近期结果优先、历史和执行记录逐步加载、原图标、整轮折叠、文件浏览、模型与思考强度、权限、主题字体、反馈和赞助。

三种专用版统一为 1.2.0。重点验证从 1.2 自动升级到后续版本；更早版本更新失败时可先换装完整包。桌面功能取决于本机接口能力，不等同于全部 ChatGPT 桌面功能；列表未返回的较早聊天请先在电脑打开再刷新。
