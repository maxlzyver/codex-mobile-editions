开始使用

  1. 电脑安装并登录 Codex，完整解压对应系统的 Editions 软件包和插件包。
  2. Windows 运行 Install-Plugin.ps1 -InstallationRoot '软件目录' -DefaultCwd '项目目录' -Register；macOS 运行 bash Install-Plugin.command '软件目录' --default-cwd '项目目录' --register。使用软件自带 Node.js，不需要另装运行环境。
  3. 从插件详情点击“打开”，直接进入本页；也可以在聊天中说“打开移动助手管理面板”。插件自动启动或复用后台。
  4. 选择同一 Wi-Fi 或互联网连接，生成二维码。手机扫码后，在“设备”中批准连接。
  5. 按需要开启“手机权限”。电脑保持开机、联网且不休眠。

软件版与插件版共用同一后台、设备与权限。关闭这个面板不会中断手机连接。手机沿用电脑登录，不需要第二次登录账号。

更新

“更新”分别管理插件自身和助手后台。自动更新开关默认关闭；开启后在任务空闲时安装。插件运行版本与已安装版本分别显示，出现“待 Codex 重新加载”时，新开插件会话或重启 Codex 后核对运行版本。
