# Codex 移动助手

**用手机浏览器继续电脑上的 Codex 工作，也可以直接在 Codex 内作为插件使用。**

Codex 移动助手让手机连接自己的电脑，查看聊天和任务进度、远程发送指令、上传附件，以及浏览和下载项目文件。支持 Windows 11、Windows 10 与 macOS，提供独立软件和 Codex 插件两种使用方式，并复用电脑端已有的登录。

[下载完整软件包](https://github.com/maxlzyver/codex-mobile-editions/releases/latest) · [插件安装教学](docs/V1.3.1-PLUGIN-INSTALL.md) · [完整更新日志](CHANGELOG.md)

## 独立软件与 Codex 插件

| 使用方式 | 电脑端入口 | 怎么使用 |
| --- | --- | --- |
| **独立软件** | Windows 的 `Codex-Mobile.exe` / macOS 的 `Start.command` | 启动后打开电脑管理网页，生成手机连接二维码，管理设备、权限和更新。 |
| **Codex 插件** | Codex 的“插件 → Codex 移动助手” | 在插件详情直接打开内嵌管理页面或进入设置，也可以在对话中说“打开移动助手管理面板”。无需打开软件的独立管理网页。 |

插件页面包含 **手机连接、设备、手机权限、使用说明、更新、关于** 六个栏目。手机扫码后，可直接在当前页面批准连接；设备授权与撤销、权限调整和更新设置都能在 Codex 内完成。

两种入口连接同一份本地助手后台，共享手机配对和权限设置。手机端始终使用浏览器，无需安装本工具的手机 App。插件仍需要完整软件包中的后台与运行组件，因此安装后请保留整份软件文件夹。

## 主要功能

### 分区、项目与聊天

手机侧栏按电脑中的真实 **分区 → 项目 → 聊天** 展示，保留分区顺序和独立聊天。分区与项目可以折叠，Codex 和 GPT 的展开状态分别记忆；电脑调整侧栏后，可在手机刷新同步。

可以查看已有聊天，并在已有的本机 Codex 项目下新建子聊天。桌面项目的新建、重命名和删除仍在电脑操作。GPT 列表展示桌面接口返回的项目、置顶和最近聊天；较早聊天未出现时，可先在电脑打开再刷新。

### Codex 远程对话与任务操作

- 在手机查看输出和任务状态，继续已有 Codex 聊天，或创建助手独立连接的新任务。
- 按当前连接提供的能力选择模型、思考强度，并在支持的任务运行过程中发送引导。
- 助手独立任务支持继续对话、停止后发送和审批；手机使用停止、审批功能前，需要在电脑管理端开启对应权限。
- 原桌面聊天，包括手机在桌面项目下新建的子聊天，停止和审批仍需在电脑端完成。桌面接口不可用时，页面会显示只读状态，并可使用助手独立分支继续工作。

可操作范围以页面显示的连接能力为准。助手独立任务使用电脑上的账户和文件，但不继承全部桌面专有工具。

### GPT 聊天续聊

支持在手机查看和继续已有的桌面 GPT 文字聊天，复用电脑端登录，沿用当前聊天的模型。正在生成回复时，等待本轮结束后再发送。

GPT 的新建聊天、模型切换、停止和附件发送目前在电脑端完成；手机列表不代表全部 GPT 历史记录。详细能力对照见 [Codex / GPT 功能范围](docs/V1.2.0-FEATURES.md)。

### 附件上传与项目文件

Codex 聊天支持从手机相册或文件管理器选择图片和普通文件，每条消息最多 **8 个文件**，单个最多 **25 MiB**。上传时显示进度，对话中展示图片预览、文件类型与名称，并支持附件及图片原图下载。

手机还可浏览已授权项目的真实目录，预览代码、文本和图片，打开 PDF，下载单个文件；聊天回复中的项目文件链接也可直达预览或下载。电脑端可以添加已有项目目录；获准后，手机也能选择其他本机目录。

历史文件已被清理或不在授权范围内时，会显示不可访问，不会从聊天文字中还原丢失文件。

### 对话阅读与加载体验

- 显示 Markdown、代码块、表格和数学公式，区分用户消息、回复、文件卡片和任务状态。
- 将同一轮执行过程集中折叠，公开过程说明、命令、文件修改和工具记录可按需展开；最终答复与用户指令保持可见。
- 优先显示近期问答和最终结果，逐步补载历史与执行详情，缓存已访问聊天，并保留阅读位置与折叠状态。
- 指令被服务确认接收后保留本地回执，刷新后仍可查看；真实聊天记录同步后自动去重，并区分发送中、待同步和失败状态。

### 手机连接、设备与权限

支持两种连接方式：**同一 Wi-Fi 下的局域网连接**，以及使用 Cloudflare Quick Tunnel 的**互联网临时连接**。电脑生成二维码，手机扫码并提交设备名称，再由电脑批准连接。插件模式可直接在当前页面批准，也能在设备栏目撤销已有授权。

手机沿用电脑的 Codex 登录，不需要在手机重复输入账号或 API Key。二维码两分钟有效、仅能使用一次；手机授权默认 30 天，清除 Cookie、入口变化或授权过期后需要重新配对。

以下权限分别控制，默认关闭，可在电脑网页或 Codex 插件中设置：

| 权限 | 开启后的作用 |
| --- | --- |
| 手机审批 | 在连接能力支持时，处理助手独立任务的待审批请求。 |
| 手机停止任务 | 在连接能力支持时，停止助手独立任务，并使用停止后发送。 |
| 浏览其他本机目录 | 在已授权项目之外，选择其他已有目录作为工作项目。 |

已授权项目的文件浏览保持可用。扩展目录权限只控制目录访问，不改变 Codex 的执行权限或沙箱；关闭后会隐藏手机额外添加的目录，已经明确用于任务的具体工作目录仍作为普通项目保留。

### 外观、帮助与更新

网页端支持主题、字体、字号、主色和文字颜色设置；Codex 插件采用蓝白界面和项目原图标。管理入口提供使用说明、关于、反馈和自愿赞助，赞助不影响功能使用。

软件和插件分别提供 **检查更新、一键更新、自动更新**。自动安装默认关闭；开启后发现更高版本会等待任务和审批空闲，再下载、校验并安装。软件更新保留本地设置、设备配对和项目数据，重启后台时互联网临时地址可能变化。

插件会区分运行版本与已安装版本。宿主尚未加载新代码时，页面明确显示“待 Codex 重新加载”；需要由宿主重新加载插件，安装工具不会强制重启 Codex。更新后可查看版本公告，也可在设置中重新阅读说明。

## 下载与开始使用

当前软件与插件均为 **1.3.1**。请从 [最新发布页](https://github.com/maxlzyver/codex-mobile-editions/releases/latest) 下载对应系统的完整软件 ZIP，包内已经包含插件、安装工具和教学。

| 专用版 | 系统要求 | 完整软件包 | 插件安装入口 |
| --- | --- | --- | --- |
| [Windows 11](editions/windows11/README.md) | 原生 x64，内部版本 22000+ | `codex-mobile-windows11-1.3.1-x64.zip` | `Install-Plugin.cmd` |
| [Windows 10](editions/windows10/README.md) | 22H2，内部版本 19045，原生 x64 | `codex-mobile-windows10-1.3.1-x64.zip` | `Install-Plugin.cmd` |
| [macOS](editions/macos/README.md) | macOS 14+，Apple 芯片 / Intel | `codex-mobile-macos-1.3.1-universal.zip` | `Install-Plugin.command` |

完整解压到当前用户可写的目录，保持目录结构。包内自带 Node.js 和网络连接组件，无需另装 npm；Codex 本身需在电脑上安装兼容版本。GitHub 自动生成的 **Source code ZIP 不含运行组件**，不能代替完整软件包。Windows ARM64 与 32 位系统不在支持范围，Windows 10 专用版也仍需兼容的 Codex 环境。

### 作为 Codex 插件使用

1. 完整解压软件包。Windows 双击软件根目录 **`Install-Plugin.cmd`**；macOS 双击 **`Install-Plugin.command`**。
2. 工具直接绑定这份软件并注册插件。**安装时不必提前打开 Codex**，也不用先启动助手；安装过程不控制鼠标键盘或其他窗口。
3. 完成后自行打开 Codex，进入“插件 → Codex 移动助手”，点击“打开插件”。Codex 原本已运行时，可关闭再启用插件，必要时自行重开 Codex。
4. 确认电脑端已登录 Codex，在插件页面生成二维码；手机扫码后，在当前页面点“批准连接”。

无需单独下载插件 ZIP。安装后保留软件目录，插件会在打开管理页面时启动或复用后台。详细步骤、安装日志位置和故障处理见 [插件安装教学](docs/V1.3.1-PLUGIN-INSTALL.md)。

### 作为独立软件使用

1. 在电脑安装并登录兼容的 Codex。
2. Windows 双击 **`Codex-Mobile.exe`**；macOS 双击 **`Start.command`**，按提示选择项目目录并打开电脑管理网页。
3. 点击“连接手机”，选择局域网或互联网连接；手机扫码后，由电脑批准。
4. 在手机浏览器查看聊天、发送指令或浏览项目文件。

macOS 首次运行未签名脚本时，可按系统提示在 Finder 中右键“打开”。使用期间，电脑需保持开机、联网、不休眠，助手后台持续运行；继续原桌面聊天还需要兼容的桌面连接。

## 升级与运行说明

从旧版在线升级后，助手启动时会补齐缺失的根目录插件安装入口，`tools` 内也保留安装脚本。**相同版本不会重复自动安装**：此前已经安装旧 1.3.1 而遇到安装工具问题的用户，请使用最新发布页中的 1.3.1 修复包。

旧通用版 **1.2** 与本仓库的分平台专用版属于不同版本序列，不会自动迁移。首次换装请退出旧助手，使用新完整包并重新选择项目、配对手机；电脑项目和 Codex 聊天仍在原位置。更早专用版更新失败时见 [升级说明](docs/V1.2.0-UPGRADE.md)。

插件内嵌页面需要支持 MCP Apps 的 Codex 桌面宿主。原桌面聊天与 GPT 功能依赖本机接口能力，可能随 Codex 升级变化。各版本验证记录见 [V1.3 验证记录](docs/V1.3.0-VALIDATION.md)、[发布说明](https://github.com/maxlzyver/codex-mobile-editions/releases)和 [Actions](https://github.com/maxlzyver/codex-mobile-editions/actions)。

本项目是独立社区工具，不是 OpenAI 官方客户端，也不提供账号、额外额度或多人账号隔离。局域网连接需要设备互通；互联网临时连接的地址不固定，流量经过 Cloudflare。获准手机可访问相应电脑项目，请妥善管理设备授权。

仓库与发行包只包含程序，不包含账号令牌、设备配对、聊天或项目文件。账号凭据保留在电脑端；请勿公开管理链接、二维码或使用后的 `.runtime` 目录。

- 修复指令发送后本地显示不稳定的问题：服务确认接收后保留本地回执，刷新页面不会丢失；真实聊天记录同步后自动去重，并清楚显示发送中、结果未确认和失败状态。
- 新增聊天文件直达入口：点击回复中的项目文件链接即可预览或下载，支持中文文件名、空格和行号；文件仍受已授权项目范围限制。
- 重新设计项目、模型与思考强度选择区，统一卡片、图标、字号与触屏操作间距，适配手机窄屏和深色主题。

- 新增手机权限设置：审批、停止任务、浏览其他本机目录分别控制，默认关闭，仅电脑管理端可开启。扩展目录权限不会改变 Codex 的执行权限或沙箱。
- 更新后首次打开显示版本公告，并可在设置中重新查看；首次使用提示权限入口。

当前桌面原会话接口未提供停止或审批能力；这些操作仅适用于移动助手创建、且当前连接支持的任务。

本版回归详情以发布记录和对应 [Actions](https://github.com/maxlzyver/codex-mobile-editions/actions) 结果为准。历史测试结果不代表本次验证，也不代表已向真实 Codex 聊天发送测试指令。
